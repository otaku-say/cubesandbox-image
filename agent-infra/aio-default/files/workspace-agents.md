# Agent 工作指南 (AGENTS.md)

## XERJ 智能检索服务

沙箱内置 AI-Native 搜索引擎 XERJ，支持 Elasticsearch 8.x 协议、零配置索引、代码段提取与 17 个原生 MCP 工具。
服务采用**透明惰性按需激活机制**（未调用时不占用任何内存与 CPU；首次调用自动秒级就绪）。

### 核心规则
1. **禁止全库大面积 grep/rg**：大范围文本扫描会输出数千行冗余文本撑爆上下文窗口。
2. **优先使用 xerj 代码与文档检索**：
   - 建立索引：`xerj autoindex <目录或项目路径>`（1~2秒自动提取文本与代码）
   - 代码搜索：`xerj search "<搜索词或自然语言描述>"`（自带定义优先加权，仅返回行号与关键代码块，节约 2.7x Token）
   - 定义直达：`xerj def "<函数/类/符号名>"`（快速跳转至符号定义位置）
   - 开源范式：`xerj ask "<技术实现问题>"`（从开源语料库检索成熟解法）
3. **MCP 调用**：项目根目录已预置 `.mcp.json`，支持直接调用 `xerj_search`、`xerj_def`、`xerj_code_search` 等工具。
4. **内存管理**：若检索完成希望彻底释放后台内存，可随时运行 `xerj-service stop`。
